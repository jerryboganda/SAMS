# Demo Data in Abundance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Populate a comprehensive medical exam-prep demo dataset in abundance across the database via a strictly 1-time Sequelize migration and updated seeders, guaranteeing zero re-generation on builds/restarts and full permanent deletion via the Admin Panel.

**Architecture:** A dedicated Sequelize migration (`20260101000037-seed-abundance-demo-data.cjs`) leverages `SequelizeMeta` to guarantee execution occurs exactly once during production deployment migrations (`npm run migrate`). Seed data modules supply rich courses, 500+ questions, 5 mock exams, students, enrollments, test session analytics, faculty, coupons, FAQs, and announcements. Standard dev seeders in `server/src/db/seeders/` are synchronized with the same dataset.

**Tech Stack:** Node.js 20, Express, Sequelize ORM, MySQL 8 / MariaDB, Jest, Supertest.

## Global Constraints
- Runtime: Node.js 20 LTS.
- DB: MySQL 8 / MariaDB (InnoDB, `utf8mb4_unicode_ci`).
- Migrations: `sequelize-cli` via CommonJS (`.cjs`).
- Zero scope drift: No changes to authentication models, payment gateway adapters, or security middleware.
- Integrity: All foreign keys, ON DELETE cascades, and uniqueness constraints must be strictly respected.
